Write a Python script using the official Anthropic SDK that implements a basic multi-agent router pattern based on a YAML configuration file.

Requirements:
1. Parse a YAML file containing a list of `agents` (each with a `name`, `model`, `temperature`, and `system_prompt`).
2. Create an Orchestrator function that takes a user query and decides which of the 3 agents (`python-scripter`, `data-engineer`, or `front-end-specialist`) to route the request to.
3. Execute the Anthropic API call using the selected agent's specific model and system prompt.
4. Include print statements that calculate and log the token usage (input/output) to demonstrate the communication overhead mentioned in our architecture design.
5. Keep the code concise and PEP-8 compliant.
