Every factorization here is the closed-form answer to a constrained optimization problem — you just don’t usually see the constraint written down. QR is OLS refusing to square its condition number. Truncated SVD is the provably best solution to “compress this matrix.” Eigendecomposition falls out of maximizing variance along one direction instead of building two orthogonal bases. NMF is SVD’s optimum with a sign constraint bolted on. Cholesky is a positive-definite solve that stops re-deriving the inverse every time. Picking a factorization is picking which constraint buys stability, compression, or interpretability.

Squaring the condition number is the hidden cost of the normal equations

Ordinary least squares minimizes \(\|y-X\beta\|_2^2\), solved by the normal equations \(\hat\beta=(X^TX)^{-1}X^Ty\). The catch is conditioning: since \(X^TX\)’s eigenvalues are \(X\)’s squared singular values, \(\kappa(X^TX)=\kappa(X)^2\) — that’s the one-line proof, straight from the definition of \(A^TA\)’s eigenvalues. Solving with a matrix that ill-conditioned amplifies floating-point error roughly as \(\kappa(X)^2\varepsilon\) instead of \(\kappa(X)\varepsilon\). Factor \(X=QR\) with \(Q\) orthonormal (\(\kappa(Q)=1\)) and substitute into the normal equations: \(R^TQ^TQR\beta=R^TQ^Ty \Rightarrow R^TR\beta=R^TQ^Ty\), and since \(R^T\) is invertible, \(R\beta=Q^Ty\). Back-substitution solves this in \(O(n^2)\), conditioned on \(\kappa(X)\) — never \(\kappa(X)^2\) — because \(X^TX\) is never formed.

Code 
# Build X with a controlled condition number instead of a raw high-degree
# Vandermonde basis, whose columns are so nearly dependent that beta itself
# becomes ill-posed, not just numerically delicate -- singular values decaying
# geometrically isolate the conditioning effect the derivation is about.
n, p = 200, 12
U0, _ = np.linalg.qr(rng.normal(size=(n, p)))
V0, _ = np.linalg.qr(rng.normal(size=(p, p)))
singvals = np.logspace(0, -6, p)  # cond(X) ~ 1e6, cond(X.T @ X) ~ 1e12
X = (U0 * singvals) @ V0.T

beta_true = rng.normal(size=p)
y = X @ beta_true  # noiseless: recovery error below is pure floating-point conditioning

print(f"cond(X)     = {cond(X):.3e}")
print(f"cond(X.T@X) = {cond(X.T @ X):.3e}")

beta_normal = solve(X.T @ X, X.T @ y)
Q, R = qr(X, mode="economic")
beta_qr = solve_triangular(R, Q.T @ y)

print(f"||beta_normal - beta_true|| = {np.linalg.norm(beta_normal - beta_true):.2e}")
print(f"||beta_qr - beta_true||     = {np.linalg.norm(beta_qr - beta_true):.2e}")
cond(X)     = 1.000e+06
cond(X.T@X) = 1.000e+12
||beta_normal - beta_true|| = 2.70e-05
||beta_qr - beta_true||     = 5.63e-12

Truncating the SVD is the only rank-k approximation optimization can’t beat

Truncated SVD isn’t just a good low-rank approximation — Eckart-Young-Mirsky says it’s the best one, full stop. For \(A=U\Sigma V^T\) and any \(B\) with rank\((B)\le k\), \(\|A-B\|_F\ge\sqrt{\sum_{i>k}\sigma_i^2}\), with equality exactly at \(A_k=\sum_{i\le k}\sigma_iu_iv_i^T\). The proof runs through Courant-Fischer: any rank-\(k\) \(B\) vanishes on some \((n-k)\)-dimensional subspace, which lower-bounds its residual by the tail singular values no matter how \(B\) is chosen. That’s a statement about every rank-\(k\) matrix, not just other factorizations — nothing beats truncated SVD on Frobenius error at a given rank.

Code 
A = rng.normal(size=(60, 40))
U, s, Vt = svd(A, full_matrices=False)

k = 10
A_k = (U[:, :k] * s[:k]) @ Vt[:k]
residual_frobenius = np.linalg.norm(A - A_k, "fro")
tail_bound = np.sqrt(np.sum(s[k:] ** 2))
print(f"||A - A_k||_F    = {residual_frobenius:.6f}")
print(f"sqrt(sum tail^2) = {tail_bound:.6f}")
||A - A_k||_F    = 32.942888
sqrt(sum tail^2) = 32.942888

The same variational argument that optimizes SVD also diagonalizes a symmetric matrix

That same Courant-Fischer argument, applied to one symmetric matrix instead of two orthogonal bases, gives eigendecomposition. Maximize projected variance \(v^TAv\) subject to \(\|v\|=1\); the Lagrangian \(\mathcal L(v,\lambda)=v^TAv-\lambda(v^Tv-1)\) has stationarity condition \(\nabla_v\mathcal L=2Av-2\lambda v=0\Rightarrow Av=\lambda v\) — eigenvectors are exactly the Rayleigh quotient’s stationary points, eigenvalues the stationary values, and \(A=Q\Lambda Q^T\) falls out by repeating the maximization on the orthogonal complement already found. For \(\Sigma=X^TX\), eigenvalues of \(\Sigma\) are \(\sigma_i(X)^2\) — the same identity from above. Eigendecomposing a covariance matrix directly inherits the normal equations’ \(\kappa(X)^2\) instability; SVD on the centered data instead sidesteps it, the same fix as before.

Code 
Xc = X - X.mean(axis=0)
Sigma = Xc.T @ Xc

eigvals, eigvecs = eigh(Sigma)
_, s_centered, _ = svd(Xc, full_matrices=False)

print(f"top eigenvalues:          {np.sort(eigvals)[::-1][:4].round(3)}")
print(f"top squared singular vals: {(s_centered[:4] ** 2).round(3)}")
print(f"cond(Sigma) = {cond(Sigma):.3e}   cond(Xc) = {cond(Xc):.3e}")
top eigenvalues:          [0.989 0.08  0.007 0.001]
top squared singular vals: [0.989 0.08  0.007 0.001]
cond(Sigma) = 9.911e+11   cond(Xc) = 9.955e+05

Forcing nonnegativity trades optimality for interpretability

SVD’s optimum is sign-unconstrained, so its components routinely cancel — a factor can subtract as much signal as it adds, a poor model of “parts.” NMF restores interpretability by adding a constraint: \(\min_{W,H\ge0}\|V-WH\|_F^2\). Lee and Seung’s multiplicative update preserves nonnegativity automatically and provably decreases the objective every step: \[H\leftarrow H\odot\frac{W^TV}{W^TWH},\qquad W\leftarrow W\odot\frac{VH^T}{WHH^T}\] The cost: the objective is only biconvex, not jointly convex, so this converges to a stationary point, not the global one, and it’s sensitive to initialization — nndsvda is a deterministic fix for that, not a guarantee.

Code 
V_demo = rng.gamma(shape=2.0, scale=1.0, size=(50, 30))
demo_model = NMF(n_components=5, init="nndsvda", max_iter=500, random_state=7)
W_demo = demo_model.fit_transform(V_demo)
H_demo = demo_model.components_
print(f"reconstruction error = {demo_model.reconstruction_err_:.4f}")
print(f"W, H nonnegative: {(W_demo >= 0).all()}, {(H_demo >= 0).all()}")
reconstruction error = 41.9530
W, H nonnegative: True, True

Factor once, solve many times: Cholesky turns O(n^3) into O(n^2) per query

A symmetric \(A\) factors as \(A=LL^T\) with positive diagonal \(L\) iff it’s SPD — equivalently, citing the spectral theorem above rather than asserting it fresh, iff every eigenvalue of \(A\) is positive. Cholesky costs \(O(n^3/3)\), half of general LU, by exploiting symmetry; each subsequent solve is \(O(n^2)\) via substitution. For \(m\) right-hand sides sharing \(A\): \(O(n^3+mn^2)\) total, versus forming \(A^{-1}\) explicitly at similar asymptotic cost but worse constants and worse conditioning — never invert to solve. For covariance-structured data, \(x=Lz\) with \(z\sim\mathcal N(0,I)\) gives \(x\sim\mathcal N(0,\Sigma)\): Cholesky is the sampling mechanism, not just the solver.

Code 
sizes = [50, 100, 200, 400, 800]
factor_times, inv_times = [], []
for size in sizes:
    Rm = rng.normal(size=(size, size))
    Am = Rm @ Rm.T + size * np.eye(size)
    Bm = rng.normal(size=(size, 5))

    t0 = time.perf_counter()
    c, low = cho_factor(Am)
    cho_solve((c, low), Bm)
    factor_times.append(time.perf_counter() - t0)

    t0 = time.perf_counter()
    np.linalg.inv(Am) @ Bm
    inv_times.append(time.perf_counter() - t0)

fig, ax = plt.subplots(figsize=(6, 4))
ax.loglog(sizes, factor_times, "o-", color=ACCENT, label="cho_factor + cho_solve")
ax.loglog(sizes, inv_times, "o-", color=GREY, label="explicit inverse")
ax.set_xlabel("matrix size n")
ax.set_ylabel("wall-clock seconds")
ax.set_title("Factor once, solve many: Cholesky vs. explicit inverse")
ax.legend()
plt.show()

Held-out accuracy degrades toward zero as marker count nears the 450 training lines — real overfitting, the reason genomic selection never runs plain OLS at genome-wide marker density. Conditioning explains the risk underneath: \(\kappa(X)\) and \(\kappa(X^TX)\) both grow by orders of magnitude as \(p\to n\), but \(\kappa(X^TX)\) — normal equations’ effective conditioning — outpaces \(\kappa(X)\) by exactly the squaring from the opening section, burning through double precision’s \(\sim\!10^{16}\) margin at roughly half the marker count QR can still handle. That’s the real mechanism behind why breeding programs use ridge-shrunk GBLUP instead of raw least squares — exactly what the same real markers do next.

The same 350 markers build \(G\propto XX^T\), the genomic relationship matrix. Cholesky-factoring \(G\) and sampling \(x=Lz\) is the actual mechanism GBLUP uses to simulate correlated breeding values:

Code 
G = (X_sub @ X_sub.T) / X_sub.shape[1]
G += 1e-6 * np.eye(G.shape[0])  # ridge for numerical PD
L = cholesky(G, lower=True)
breeding_values = L @ rng.normal(size=G.shape[0])
print(f"sampled breeding values: mean={breeding_values.mean():.3f}, var={breeding_values.var():.3f}")
sampled breeding values: mean=0.000, var=0.137

Eigendecomposing that same \(G\) — the identity from two sections above, now applied instead of proved — recovers population-structure axes among the 599 real lines:

wheat.sets in this data is a real CV-fold assignment, not a population label, so this scatter is shown unsupervised rather than colored by an invented group. Human GWAS calls this exact calculation EIGENSTRAT and includes it as covariates to keep subpopulation differences from masquerading as marker-yield associations — the same correction applies wherever a breeding panel mixes lineages.

Nonnegative factors split real leukemia expression into the diagnosis nobody told the model

Golub et al. profiled real bone-marrow samples from 72 leukemia patients on Affymetrix microarrays in 1999, founding molecular cancer classification; Brunet et al. reused this exact data in 2004 to introduce NMF-based tumor subtyping.

    id_cols = [c for c in raw.columns if not c.startswith("call") and c not in ("Gene Description", "Gene Accession Number")]
    return raw[id_cols].to_numpy(dtype=float).T, [int(c) for c in id_cols]

That’s the real precedent for expression-based subtyping that now routes patients to different treatment protocols — ALL and AML take materially different regimens, so a subtype call carries real clinical stakes. Nonnegativity is what makes \(W,H\) legible as two real gene programs instead of signed components that could just as easily cancel.

The constraint was always the point

Every factorization here traded one thing for another: QR traded forming \(X^TX\) for a triangular solve; SVD traded an exact fit for the provably best approximate one; eigendecomposition traded two orthogonal bases for one, on a single symmetric matrix; NMF traded SVD’s unconstrained optimum for a sign constraint that costs convexity but buys interpretability; Cholesky traded an inverse for a triangular factor reused across solves. None of that is incidental — the constraint you add to \(\min\|A-\hat A\|\) decides what the answer is allowed to mean, checked here against real telemetry, real breeding lines, and real diagnoses instead of a synthetic stand-in. The constraint was always the point.
